01What the Product Directory does

One place for every product your vendors send — and a robot that puts each one on the right Shopify websites, at the right price, in the right words.

Every product a vendor sends lands in Products. From there the app works on its own, every minute: it reads the photos and the vendor's text, decides which of your Shopify websites the product belongs on, works out the selling price for each website, writes a title, description and Google (SEO) text in that website's own style, adds that website's tags, and puts the product on the store.

How one product travels

  1. Lands — a product comes in. Today you add it in Products → + Add product; soon it will come straight from the Telegram channel. Status: New.
  2. Read — the AI looks at the photos and the vendor's post and fills in name, category, fabric, colour, sizes, cost price and other details (work, occasion, wash care…). Status: Reading, then Ready — or Needs info when the cost price or the category is missing.
  3. Sorted — each website's Routing rules decide whether the product goes there. Every "yes" becomes a *listing*: one product on one website.
  4. Priced and written — for each listing the price is worked out from the cost with that website's formula, and that website's AI writer writes the title, description, SEO text, tags and photo descriptions.
  5. Published — the listing is sent to Shopify: live, as a draft, or held until someone approves it — whatever that website's Publishing mode says.
Tip One product can be on several websites, each with its own price, title, description and tags. Changing one website never changes another.

  • Admins, managers and operators can use every page: add and edit products, approve, publish, change website settings.
  • Only an admin or manager can save a store's credentials (the Shopify keys).

02Before you start: categories, the AI reader and vendors

Ten minutes, once. Everything after this depends on it.

Categories

  1. Open Settings → Categories.
  2. Type each category you sell and press Enter — for example Saree, Kurta Set, Lehenga, Dupatta, Co-ord Set. You can paste several at once, separated by commas.
  3. Tap Save categories.

The AI must pick one of these for every product. A product without a category waits in Needs info. Routing rules, tags and the Shopify product type all use the category, so spell each one exactly the way you want it to appear on your websites.

The AI that reads products

  1. In Settings → AI that reads products, pick a Model and an Effort. Haiku 5.5 with Model default is enough for reading.
  2. Tap Save reader.

This AI only reads (fills in the facts). Each website chooses its own writer later, under Websites → Content & AI.

Vendors

  1. Open Vendors → + Add vendor.
  2. Name: the vendor as you know them, e.g. Rangoli Creations.
  3. Short code (optional): two or three letters, e.g. RG. Tags can use it as {vendor_code}.
  4. Tap Save vendor. Repeat for each vendor.
Tip Stopped buying from someone? Tap Deactivate instead of deleting. Their old products stay; they just stop showing up as a choice for new ones.

03Step 1 — Add and connect each Shopify store

Do this once for every website. You need the store's myshopify.com address and a Shopify login that is allowed to install apps (the store owner, or staff with that permission).

Add the website

  1. Open Websites → + Add website.
  2. Name: how you call it, e.g. Indya Ethnic.
  3. Store domain: the myshopify.com address, e.g. indya-ethnic.myshopify.com — find it in Shopify admin → Settings → Domains. Not your own .in / .com domain.
  4. Tap Add website. The website opens on its Connection tab.

A new website starts Off with the routing set to Do not list it, so nothing is sent until you have finished setting it up.

Which way to connect?

Your situationWhat you useIn the app pick
The store already has an older custom app made inside the Shopify admin, with an Admin API access token that starts shpat_That app's access tokenAccess token
Anything else — a new store, or no such appA new app from the Shopify Dev DashboardClient ID + secret
Note Shopify stopped letting anyone create new "legacy" custom apps in the store admin on 1 January 2026. Old ones keep working. Every new connection is made in the Shopify Dev Dashboard (Way B).

Way A — an existing custom app (token starting shpat_)

  1. In the Shopify admin open Settings → Apps and sales channels → Develop apps, and open the app.
  2. Check its Admin API scopes include write_products, read_products, write_publications, read_publications — plus write_inventory if this website will track stock. If you add any, save and reinstall the app when Shopify asks.
  3. Copy the Admin API access token (it starts with shpat_). Shopify shows it only once — if nobody saved it, use Way B instead.
  4. In the app: Websites → your website → Connection. Under How the app signs in pick Access token, paste it into Admin API access token, tap Save credentials.

Way B — a new app from the Shopify Dev Dashboard

  1. Sign in to the Shopify Dev Dashboard (dev.shopify.com) with a Shopify account in the same organisation as the store. An app from another organisation cannot connect to the store.
  2. Create an app, e.g. DailyOffice Product Directory.
  3. In the app's access settings add the scopes write_products, read_products, write_publications, read_publications — plus write_inventory if this website will track stock. Release that version.
  4. Install the app on the store and approve it.
  5. Open the app's settings and copy the Client ID and the Client secret.
  6. In the app: Websites → your website → Connection. Under How the app signs in pick Client ID + secret, paste both, tap Save credentials.
Tip Shopify renames its screens now and then. If a label above looks different, follow the same idea: create app → give permissions (scopes) → release → install on the store → copy client ID and secret.

Test, then switch on

  1. Tap Test connection.
  2. Green Connected to <store name>. All needed permissions are there. — done.
  3. Yellow Missing permissions: … — add those scopes to the app in Shopify, reinstall / approve it, then Test connection again.
  4. Red Last problem: … — the details are wrong or the app was removed. Copy them again, Save credentials, test again.
  5. Finish Steps 2 to 6 below for this website. Then come back to Connection and switch Active on.
  • Active can only be switched on after a successful connection. Off = nothing new is sent to this store; products already there stay.
  • Credentials are kept on the server only and are never shown again — the boxes stay empty. Leave them empty to keep what is saved; type only to replace.
  • With Client ID + secret the app renews its Shopify access by itself. Nothing to do.
  • Moving a website to a different Shopify store: change Store domain, enter that store's credentials and tap Save credentials. The website is switched off, the old store's keys are deleted, and its products are queued to be sent again to the new store. Products already on the old store stay there.

04Step 2 — Decide which products go to this website

Websites → your website → Routing rules.

When no rule matches

ChoiceWhat it means
Do not list it (safe default)Nothing goes to this store unless a rule sends it. Recommended.
List everythingEvery product goes to this store unless a rule keeps it off.

This choice is saved with Save changes at the bottom of the screen. Rules save on their own.

Add a rule

  1. Tap + Add rule.
  2. Rule name — for you, e.g. Silk sarees from Rangoli or Nothing under ₹500.
  3. When a product matches — Send it to this store or Keep it off this store.
  4. Fill only the conditions you need. Every condition you fill must match; empty ones are ignored: Vendors, Categories, Fabrics (any of these, capital letters do not matter), Cost from ₹ / Cost up to ₹ (the vendor cost), Keywords (any of these words in the name, SKU, details or what the AI read).
  5. Optional, for "Send" rules: switch on Own price for these products and set a Markup % and Add ₹ that replace the website's own for these products.
  6. Tap Save rule.

Order matters

Rules are checked from the top. The first switched-on rule that matches decides, and the rules below it are not looked at. Use the ↑ ↓ buttons to change the order. Put "Keep it off" rules above wide "Send" rules.

#RuleShown as
1Nothing under ₹300KEEP OFF · cost ₹0–₹300
2Bridal lehengasSEND · Lehenga · words: bridal · own price: +150% + ₹200
3Silk sarees from RangoliSEND · vendor Rangoli · Saree · fabric Silk

With "When no rule matches" set to Do not list it: a ₹250 silk saree from Rangoli is stopped by rule 1. A ₹1,800 silk saree from Rangoli is sent by rule 3. A cotton kurta matches no rule, so it is not listed.

  • A rule with no conditions matches every product (the app warns you).
  • The switch on a rule turns it off without deleting it.
  • A change applies to products that arrive or are checked again after it. For older products, open the product and tap Check websites again.
  • Deleting a rule never removes products that are already listed.

05Step 3 — Set the selling price

Websites → your website → Pricing. The price in the vendor's post is your COST; each website turns it into its own selling price.

Selling price = cost × (1 + Markup % ÷ 100) + Add ₹, then rounded, and never below the minimum price.

BoxWhat to type
Markup %100 doubles the cost, 80 adds 80%.
Add ₹ (after markup)A fixed amount on top — shipping, packing, payment charges.
RoundingHow the final number looks (table below).
Compare-at % (was price)0 = no struck-out price. 30 = show a "was" price 30% higher.
Minimum price ₹Never sell below this. Empty = no minimum.

Worked example: cost ₹640, Markup 80%, Add ₹60

640 × 1.8 = 1,152, plus 60 = ₹1,212 before rounding.

RoundingHow it works₹1,212 becomes
No roundingKept as it is (to the paisa)₹1,212
Nearest 10To the nearest ten₹1,210
Ends in 99Up to the next …99. A price already ending in 99 stays (₹1,299 stays; ₹1,300 → ₹1,399)₹1,299
Ends in 49 / 99Up to the next …49 or …99₹1,249

Compare-at (the struck-out "was" price)

With Ends in 99 and Compare-at % 30: 1,299 × 1.3 = 1,688.70, rounded the same way → shoppers see ₹1,699 struck out next to ₹1,299.

Minimum price

Cost ₹250: 250 × 1.8 + 60 = 510 → Ends in 99 → ₹599. With Minimum price ₹ 799 the website sells it at ₹799. The minimum is applied after rounding, so choose a "nice" number like 799 or 999.

A rule's own price

The "Bridal lehengas" rule above uses +150% + ₹200. Cost ₹6,000: 6,000 × 2.5 + 200 = 15,200 → Ends in 99 → ₹15,299. Rounding, compare-at and the minimum still come from the Pricing tab.

Tip Use the Preview box: type a Sample cost ₹ to see the price, the struck-out price and your margin before you tap Save changes.

New pricing applies to listings written from now on. A listing already on Shopify keeps its price until you open it and tap Regenerate (or type a new price yourself).

06Step 4 — Tags in this website's structure

Websites → your website → Tags. Each store filters and builds collections from tags in its own way — one may use "Fabric_Silk", another plain "silk". This tab sets the pattern for this store.

  • Tag templates — each line becomes one tag. Type it and press Enter. Words in curly brackets are filled from the product.
  • Fixed tags — added to every product sent to this store, e.g. New Arrival.
  • Letter case — As written, lowercase or Title Case.
  • AI extra tags — switch on to let the AI add style / occasion tags it sees in the photos and text, up to At most tags.
PlaceholderFilled withExample
{category}The categorySaree
{fabric}The fabricBanarasi Silk
{color}The colourMaroon
{vendor}Vendor nameRangoli
{vendor_code}Vendor short codeRG
{size}One tag per sizeSize_S, Size_M, Size_L
{sku}Product codeRG-101
{attr:occasion}Any detail the AI read — work, occasion, pattern, set_contents, wash_care…Festive

Example

Templates {category}, Fabric_{fabric}, Color_{color}, Size_{size}, Vendor_{vendor_code}, Occasion_{attr:occasion} and the fixed tag New Arrival, for a maroon Banarasi silk saree from Rangoli (RG), Free Size, festive, give:

Saree Fabric_Banarasi Silk Color_Maroon Size_Free Size Vendor_RG Occasion_Festive New Arrival

  • If a placeholder is empty for a product, that tag is skipped — you never get a half tag like "Fabric_".
  • Commas inside a tag become spaces (Shopify splits tags at commas). Repeats are removed, whatever the capital letters.
  • The Example box at the bottom of the tab shows the tags for a sample product as you type.
  • Shopify's product type is set to the category automatically.

07Step 5 — Titles, descriptions and SEO

Websites → your website → Content & AI. For every listing one AI call writes the title, description, SEO title, SEO description, web address (handle), extra tags and photo descriptions — in this website's voice.

Model and effort

ModelGood forCost
Haiku 5.5Fast; good for most listingsLowest
Sonnet 5.5Better writing — your main storeAbout 20 × Haiku
Opus 5.5The best writing — a premium storeHighest

Effort (Model default, Low, Medium, High, Extra high, Max) is how hard the model thinks before writing. Higher is slower and costs more. Model default suits most listings; models that do not support effort ignore it.

Tip Start every website on Haiku 5.5 with Model default. Read 10–20 listings. Move a website up to Sonnet only if its writing is not good enough.

The other settings

SettingWhat it does
LanguageEnglish, Hinglish, Hindi…
Brand voiceHow this store talks, e.g. "premium, elegant, festive — for brides and wedding guests".
Image alt textOn: the AI describes each photo for Google and for screen readers.
Title pattern{ai_title} lets the AI write the title. Or build it: {color} {fabric} {category} → "Maroon Banarasi Silk Saree". Also usable: {vendor}, {sku}, {name}; mix them, e.g. {ai_title} {sku}.
Length limitsTitle (characters), Description (words), SEO title (characters) (Google shows about 60), SEO description (characters) (about 155).
Extra instructionsAnything to always do or avoid, e.g. "Mention free shipping above ₹1,999. Never use the word cheap."
Note The AI is told to use only the facts given and never to invent a fabric or size. Still, read the first listings of every new website before you set it to Live.

Descriptions use only simple formatting (paragraphs, bullet points, bold, italics, line breaks), so they look right on any Shopify theme. Save the tab with Save changes.

08Step 6 — Publishing mode, the Active switch and pausing

Websites → your website → Publishing.

Publishing modeWhat happensUse it when
LivePublished and visible on the store straight awayYou trust this website's setup
DraftSent to Shopify as a draft — someone makes it visible inside ShopifyYou want a last look inside Shopify
Review firstWaits in Products as Needs review until someone taps Approve, then publishesA new website, the first weeks

Track stock — on: Shopify counts stock and stops selling at 0 (the app needs write_inventory); set quantities in Shopify after publishing. Off: always orderable — right for made-to-order or vendor-held stock.

Three ways to stop things

SwitchWhereWhat it does
Active (one website)Websites → website → ConnectionOff = nothing new is sent to this store. Products already there stay.
Rule switch (one rule)Websites → website → Routing rulesThat rule stops sorting products.
Automation (everything)Settings → AutomationPaused = nothing is read, written or published on its own. Buttons like Publish now still work. The Dashboard shows a yellow banner.

Settings → Run now does one round straight away (it can take up to 2 minutes) and shows how many products were read, routed, written, published and failed.

A safe first day for a new website

  1. Set Publishing mode to Review first and tap Save changes.
  2. On Connection, switch Active on.
  3. Add three or four real products in Products.
  4. Open each one, open this website's listing, read it, fix anything, tap Approve.
  5. Check the products on the store. Happy? Switch Publishing mode to Live.

09Daily use — adding a product

  1. Tap + Add product (on Products or on the Dashboard).
  2. Photos — add one or more (JPG, PNG or WEBP). The first photo is the main one.
  3. Vendor — pick one, or create a new vendor right there.
  4. Cost price (₹) — the vendor's price to you.
  5. SKU — optional, your product code.
  6. Details — paste the vendor's whole post: fabric, colour, sizes, work, price.
  7. Category and Sizes — optional. Leave Let the AI decide and the AI fills them in.
  8. Tap Add product. The product opens; within a minute the AI reads it and the websites pick it up.
  • You need at least a photo, the details text or a SKU.
  • Whatever you type yourself is kept exactly as you wrote it — the AI only fills empty boxes.
Tip The better the post you paste, the better the listing. Fabric, colour and sizes in the text help the AI more than the photo alone.

11Working with listings

Open a product, then tap a website in its Websites box. The listing opens with its price, title, description, SEO, handle and tags, and the buttons below.

Fixing a failed listing

  1. On the Dashboard tap Failed to publish (or filter Products by Listing: Failed).
  2. Open the product, then the website shown with the red text.
  3. Read the red text and fix the cause — see Troubleshooting.
  4. Tap Publish now (or Update on Shopify if it is already there).

The app also tries again by itself — up to 3 times, 10 minutes apart — so a short Shopify hiccup clears on its own.

Editing, and "kept" fields

Change any of Price (₹), Title, Description, SEO title, SEO description, Handle (URL) and Tags (comma list), then tap Save changes. Each field you change gets a small kept label: Regenerate will never touch it. Product Facts work the same way — a box you typed is kept and the AI reader never overwrites it.

Tip To hand a field back to the AI: empty the box, tap Save changes, then Regenerate. This works for price, title, description and both SEO fields.
  • On a published listing, after Save changes tap Update on Shopify to send the change.
  • While a listing is Writing or Publishing, editing is off. Close it and open it again in a minute.
  • Once a product is on Shopify its web address (handle) never changes, so old links keep working.

13Questions people ask

Does the app ever delete a product from Shopify?

No. Remove from site only sets it to Draft. Archive does not touch Shopify at all.

I changed a website's pricing / tags / writing. Are old products updated?

Not by themselves. New listings use the new settings. To update one already on Shopify, open it and tap Regenerate (and Update on Shopify if it does not go by itself).

Can one product have a different price on each website?

Yes. Every website has its own formula, and a rule can give a group of products its own markup.

The vendor's post shows a retail price, not our cost. What then?

The app always treats the number as your cost. Type your real cost in Cost price (₹) — what you type is kept.

Will the AI make things up?

It is told to use only the facts given and never to invent a fabric or size. Read the first listings of each website; anything you correct is kept.

What does the AI cost?

One AI call reads each product, and one call writes each listing on each website. Haiku is the cheapest; use Sonnet or Opus only where the writing really matters.

Are prices with or without GST?

The app sends the number from your formula. Whether Shopify treats prices as including tax is set in Shopify (Settings → Taxes and duties).

Who can see the Shopify keys?

Nobody. They are stored on the server, used only to talk to Shopify, and never shown again in the app.

What happens when I pause automation?

Nothing runs on its own until you switch it back on; buttons on a product still work. When it is switched on again it carries on from where it stopped.

Two of us edited the same listing. Whose change stays?

The last one saved. Close and reopen a listing before editing if someone else may have just changed it.

14What is coming next

Telegram intake

Soon every product posted in the vendors' Telegram channel will land in Products by itself — photos and text together — and go through exactly the same steps: read, sorted, priced, written, published. The same post arriving twice is ignored.

  • Until then, add products with + Add product.
  • Nothing to set up for it today: the categories, vendors and website rules you make now are the ones Telegram products will use.
